# GitHub setup

This file is for whoever manages the GitHub repository. You do not need it to use ThinkTank.

## Repository description

GitHub limits the description field and displays it in search results and on the profile. One line, ready to paste:

```
An engineering engine for Claude Code: agentic RAG over local Qdrant, an acceptance-gated delivery loop with maker/checker separation, and an EU AI Act compliance rung.
```

## Topics

People browsing GitHub use topics to find repositories, and adding them costs nothing. Suggested set:

```
claude-code
rag
qdrant
graphrag
ai-agents
eu-ai-act
agentic-workflows
llm-tooling
```

Add them under Settings or from the repository home page by clicking the gear icon next to About.

## When editing the README

Keep the "What is not included, and what does not work" section intact. It is the part that tells a
reader where the project breaks before they depend on it, and removing it would leave the feature
list unbalanced.
